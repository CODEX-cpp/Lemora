Interface

The main window, point by point

  1. Search

    Searches by name, address or user across all clients. The menu to the right of the field picks the protocol for a quick connection to an unsaved address.

  2. Add

    New connection in the open folder, with Ctrl+N.

  3. Filters and views

    All, RDP only or VNC only; list, cards or tree.

  4. Clients

    One folder per client, with subfolders for site, network and servers. The number on the right counts the connections.

  5. Connections

    Protocol, address with port, user. The star adds the connection to the favorites; the arrow opens the actions.

  6. Folder summary

    Network 10.20.0.0/24 and domain BRENTA: the connections inside inherit them. Below, how many credentials and device passwords the folder holds. Product, P.1

  7. Options

    Settings with Ctrl+I: themes, protocols, vault, extension, MCP server.
